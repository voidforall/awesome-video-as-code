# Contribution Guidelines

Thank you for helping improve Awesome Video as Code.

## What Belongs Here

A submission should directly help people create videos from code written or directed by AI agents. Good candidates include actively maintained rendering frameworks, agent skills, production tools, source-available showcases, first-party learning material, and relevant research.

Please do not submit generic text-to-video products, ordinary video editors, promotional landing pages without usable documentation, archived projects, or resources whose connection to video as code is incidental.

## Before Submitting

- Search the README and open pull requests for duplicates.
- Use the project's canonical URL, preferably its official repository or documentation.
- Confirm that the resource is maintained, documented, and usable.
- Read or test enough of the resource to recommend it personally.
- Write an objective description in your own words. Do not copy marketing copy or another list's description.
- Verify any AI-assisted research and rewrite AI-assisted prose before submitting it.

## Pull Requests

Submit one resource per pull request. Use this format:

```markdown
- [Name](https://example.com) - Objective description that starts with a capital letter and ends with a period.
```

Add new entries at the bottom of the appropriate category. Keep descriptions concise, avoid superlatives, and do not include star counts.

In the pull request, explain:

1. Why the resource is useful for video-as-code work.
2. How you verified that it fits the list.
3. Whether you are affiliated with the project.

## Updating and Removing Entries

Corrections, improved descriptions, and removal proposals are welcome. Resources may be removed when they become archived, abandoned, undocumented, unsafe, or no longer relevant to the list's scope.
